# 管理页面设计

目前我们是比较急需上传文件的能力，方便做优化功能的调优测试。

设计要点和提示词如下：

需要提供知识文件上传的管理页面，不要改动任何后端代码。单独构建独立的前端代码。

先满足最小化需求，没提到的需求不要做，比如鉴权，这种都是后面可以补的。

- 支持创建新的知识库
- 支持本地文件或者文件夹上传，文件夹上传本质其实也就是一个一个文件顺序进行传输，最后结果需要反馈出哪些文档成功，哪些文件失败。

技术栈和目录结构，可以固定参考如下模板，注意：在项目根目录下创建frontend文件夹作为该前端页面的根目录

```Plaintext
技术栈如下：
- React 18 + TypeScript
- Vite 构建工具
- Tailwind CSS 样式
- shadcn/ui 组件库
- React Router v6 路由
- React Query（@tanstack/react-query）数据请求
- axios HTTP 客户端
- React Hook Form + Zod 表单校验

目录结构如下：
src/
├── components/     # 可复用组件
│   ├── provider/   # Context Provider
│   └── ui/         # shadcn/ui 组件
├── pages/          # 页面组件
├── services/       # API 请求封装
├── hooks/          # 自定义 Hook
├── types/          # TypeScript 类型定义
├── lib/            # 工具库（axios 实例等）
└── utils/          # 工具函数
```
